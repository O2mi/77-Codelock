    Aim at a door and press E to add it. Use this for both leaves of a double door, gate pairs, or a garage with several roll-up doors.

    How it works

    Everything runs on GTA's native door system.

    Creating a lock

    1. 1 Look at a door and press E, or open New lock.
    2. 2 Add every door leaf that should share the code (up to 4), then press Enter.
    3. 3 Pick a type, a 4-digit code and an auto-close timer, then save.

    For players

    • · Aim at the door, press E and type the 4-digit code.
    • · The door unlocks for everyone and closes itself again (30s by default).
    • · Anyone who knows the current code can set a new one from the keypad.

    Notes

    • · Codes are checked on the server — they never reach a client unless you are an admin.
    • · Locks are stored in doors.json and reloaded on start.
    • · The aim key is E; players can rebind it in GTA key bindings.
